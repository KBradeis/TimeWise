    How do I get a .ics file from Google Calendar?
    1. On a computer, open calendar.google.com → Settings.
    2. Choose Import & export → Export. A .zip file downloads.
    3. Open the .zip. Each calendar is its own .ics file (your main one is named after your email).
    4. Upload that file here. To refresh later, export and upload again.
